## Overview

A simple yet elegant implementation of the classic Caesar Cipher encryption algorithm in Python. This project provides functions to encrypt and decrypt messages using a shift-based substitution cipher.
The Caesar Cipher is one of the oldest known encryption techniques, dating back to Julius Caesar. Each letter in the plaintext is shifted a certain number of places down the alphabet. This project handles both encryption and decryption with a single core function.

## Features

- Encrypts/decrypts both lowercase and uppercase letters
- Validates shift values (1-25 only)
- Handles invalid inputs gracefully
- Single function handles both encryption and decryption
- Preserves non-alphabetic characters
